# 联机匹配系统

## 基于 Vue3 + Spring Boot 的多用户联机匹配系统
## 可用于在线聊天、多人协作等场景，通常更多地作为联机模块嵌入更大项目中；

### 技术选型

#### 前端
- Vue 3
- Vant UI 组件库
- TypeScript
- Vite 脚手架
- Axios 请求库

#### 后端
- SpringBoot 3.3.0 框架
- MySQL 数据库
- MyBatis + MyBatis-Flex
- Redis 缓存（Spring Data Redis, Redisson等多种实现方式）
- Redisson 分布式锁
- Easy Excel 数据导入
- Spring Scheduler 定时任务
- Swagger + Knife4j 接口文档
- Jackson：JSON 序列化库
- 相似度匹配算法
