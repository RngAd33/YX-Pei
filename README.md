# 联机匹配系统

## 技术选型

### 前端
- Vue 3
- Vant UI 组件库
- TypeScript
- Vite 脚手架
- Axios 请求库

### 后端
- Java SpringBoot 3.3.0 框架
- MySQL 数据库
- MyBatis-Flex
- MyBatis X 自动生成
- Redis 缓存（Spring Data Redis 等多种实现方式）
- Redisson 分布式锁
- Easy Excel 数据导入
- Spring Scheduler 定时任务
- Swagger + Knife4j 接口文档
- Jackson：JSON 序列化库
- 相似度匹配算法
